# **Predictable Jokes 🤖🎤**
### *AI, ML, and Data Science Jokes — Now in Your Python code!*

Tired of debugging? Need a quick laugh? With **`predictable-jokes`**, you can now generate hilarious AI, ML, and data science jokes straight from python! 🚀  

Inspired by the book **[Predictable Jokes](https://www.amazon.com/Predictable-Jokes-Data-Driven-Analytics-Learning/dp/B0C6NZFRDP)**, this package lets you bring the best (or worst? 😆) tech humor to your command line.

---

## **📥 Installation**
You can install it directly from PyPI:
```sh
pip install predictable-jokes
```

---

## **Usage**
### **CLI Usage**
Once installed, just type:
```sh
tell-joke
```
💡 Want another joke? Just run `tell-joke` again!

### **Python Usage**
You can also use it inside a Python script or interactive shell:
```python
from predictable_jokes.jokes import tell_joke

tell_joke()
```
You can also specify the topic and complexity. Some jokes may be too smart for some people. And most jokes are too dumb for most people. 

```python

tell_joke(topic="data science", complexity="medium")
```

Example Output:

```
Did you hear about the 12th grade student that failed his machine learning exam so badly that he had to go back to 11th grade?

Classic example of Scholastic Grade Descent.
```
