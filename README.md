# **Predictable Jokes 🤖🎤**
### *AI, ML, and Data Science Jokes — Now in Your Terminal!*

Tired of debugging? Need a quick laugh? With **`predictable-jokes`**, you can now generate hilarious AI, ML, and data science jokes straight from your terminal! 🚀  

Inspired by the book **[Predictable Jokes](https://www.amazon.com/Predictable-Jokes-Data-Driven-Analytics-Learning/dp/B0C6NZFRDP)**, this package lets you bring the best (or worst? 😆) tech humor to your command line.

---

## **📥 Installation**
You can install it directly from PyPI:
```sh
pip install predictable-jokes
